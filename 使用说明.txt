  银行对账单生成系统 - 使用说明
  版本: 1.0.0
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

一、系统要求
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• 操作系统: Windows 7/8/10/11
• Python: 3.9 或更高版本
  下载地址: https://www.python.org/downloads/
• 浏览器: Chrome/Edge/Firefox（推荐 Chrome）


二、安装步骤
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 解压本文件夹到任意位置（建议: D:\对账单工具）

2. 安装 Python（如果还没安装）
   - 下载并运行 Python 安装程序
   - ⚠️ 重要: 勾选 "Add Python to PATH"
   - 点击 "Install Now"

3. 双击 "启动.bat" 运行程序
   - 首次运行会自动安装依赖库（需要联网）
   - 安装完成后会自动启动服务


三、使用方法
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 双击 "启动.bat" 启动程序

2. 浏览器会自动打开系统界面
   （如果没有自动打开，请手动访问: http://localhost:8000）

3. 生成对账单:
   ① 选择公司名称（雷石天地/镭海/成都雷石）
   ② 选择月份
   ③ 上传底表 Excel 文件
   ④ 点击"生成对账单"按钮
   ⑤ 生成成功后点击"下载 EXCEL"

4. 查看历史记录:
   - 点击顶部"历史记录"标签
   - 可以筛选、查看、下载或删除历史对账单

五、常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Q1: 双击 "启动.bat" 后闪退怎么办？
A1: 说明 Python 未安装或未添加到系统环境变量
    解决方法: 重新安装 Python，勾选 "Add Python to PATH"

Q2: 提示"依赖库安装失败"怎么办？
A2: 可能是网络问题
    解决方法:
    - 检查网络连接
    - 或手动安装: 打开 cmd，执行
      cd backend
      pip install -r requirements.txt

Q3: 浏览器打不开页面怎么办？
A3: 可能端口被占用
    解决方法:
    - 关闭其他可能占用 8000 端口的程序
    - 或修改 backend/main.py 最后一行的端口号

Q4: 生成的对账单在哪里？
A4: 在 backend/outputs/ 目录下
    也可以在"历史记录"页面点击"下载"按钮

Q5: 可以同时打开多个窗口使用吗？
A5: 不需要。启动一次后，可以在浏览器打开多个标签页使用


六、注意事项
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
⚠️ 1. 请勿删除 backend/bank_statement.db 文件
       （这是数据库，删除后历史记录会丢失）

⚠️ 2. 请勿修改 backend/ 和 frontend/ 目录下的文件
       （修改后可能导致程序无法运行）

⚠️ 3. 上传的底表文件必须是 .xls 或 .xlsx 格式

⚠️ 4. 关闭"启动.bat"窗口会停止服务
       （下次使用需要重新启动）

⚠️ 5. 定期备份 backend/bank_statement.db 文件
       （避免数据丢失）


七、数据备份
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
建议每月备份以下文件:
• backend/bank_statement.db  （历史记录数据库）
• backend/outputs/            （生成的对账单文件）

备份方法:
1. 关闭系统（关闭"启动.bat"窗口）
2. 复制上述文件到安全位置（如U盘、云盘）
3. 重新启动系统
