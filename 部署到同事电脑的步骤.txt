【准备工作】

1. 将整个 "对账单工具_打包版" 文件夹打包成 ZIP
   - 右键文件夹 → 发送到 → 压缩文件夹
   - 或使用 7-Zip、WinRAR 等工具压缩

2. 通过以下方式传给同事:
   - U盘拷贝
   - 网络共享文件夹
   - 微信/钉钉发送（如果文件不大）

【常见问题处理】

Q: 双击 "启动.bat" 闪退？
A: Python 没装好，重新安装并勾选 "Add Python to PATH"

Q: 提示 "依赖库安装失败"？
A: 检查网络连接，或手动安装:
   1. Win+R 输入 cmd 回车
   2. 输入: cd D:\对账单工具\backend
   3. 输入: pip install -r requirements.txt

Q: 浏览器打不开？
A: 可能端口被占用，重启电脑后再试


【你需要告诉同事】

1. 每次使用前双击 "启动.bat"
2. 使用完毕关闭命令行窗口

4. 定期备份 backend/bank_statement.db 文件


【Windows 防火墙可能的提示】

• 首次运行时可能弹出防火墙提示
• 点击"允许访问"即可
• 这是正常的，因为程序需要开启本地服务


【测试是否安装成功】

✓ 双击 "启动.bat"
✓ 看到 "系统已启动！" 提示
✓ 浏览器能打开 http://localhost:8000
✓ 能看到系统界面（生成对账单/历史记录）

如果以上都成功，说明部署完成！
