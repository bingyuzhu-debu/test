【第一次使用】

1. 确保已安装 Python 3.9+
   (下载: https://www.python.org/downloads/)

2. 双击 "启动.bat"

3. 等待自动安装依赖（约1-2分钟）

4. 浏览器打开 http://localhost:8000


【日常使用】

1. 双击 "启动.bat"

2. 在浏览器中使用系统

3. 完成后关闭窗口


【如果遇到问题】

请查看 "使用说明.txt" 详细文档
