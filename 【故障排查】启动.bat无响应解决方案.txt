❌ 原因 1: Python 未安装或未添加到 PATH（80% 的情况）
───────────────────────────────────────────────────

症状：
• 双击 启动.bat 一闪而过
• 或者弹出窗口但立即关闭
• 没有任何错误提示

解决方法：
1. 检查 Python 是否安装
   - Win+R 输入 cmd 回车
   - 输入: python --version
   - 如果提示 "不是内部或外部命令"，说明没装好

2. 正确安装 Python
   - 访问: https://www.python.org/downloads/
   - 下载 Python 3.11（推荐）
   - 运行安装程序
   - ⚠️⚠️⚠️ 必须勾选 "Add Python to PATH" ⚠️⚠️⚠️
   - 点击 "Install Now"
   - 安装完成后重启电脑

3. 验证安装成功
   - Win+R 输入 cmd 回车
   - 输入: python --version
   - 应该显示: Python 3.11.x


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ 原因 2: 文件被 Windows 安全中心阻止
───────────────────────────────────────────────────

症状：
• .bat 文件无法运行
• 双击没有任何反应
• 或者提示 "已被 Windows 保护"

解决方法：
1. 右键点击 启动.bat
2. 选择"属性"
3. 在"常规"标签页底部
4. 如果看到"此文件来自其他计算机，可能被阻止"
5. 勾选"解除锁定"
6. 点击"确定"
7. 重新双击 启动.bat


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ 原因 3: 杀毒软件/安全软件拦截
───────────────────────────────────────────────────

症状：
• 文件自动消失
• 360/腾讯管家弹出拦截提示

解决方法：
1. 将整个文件夹添加到杀毒软件白名单
2. 或暂时关闭杀毒软件（运行后再开启）

   ✓ 推荐: D:\tools\reconciliation
   ✓ 推荐: C:\work\对账单工具

❌ 原因 5: 解压不完整
───────────────────────────────────────────────────

症状：
• 提示找不到 backend 目录
• 提示找不到 main.py

解决方法：
1. 删除当前文件夹
2. 重新解压完整的 ZIP 文件
3. 确保看到以下目录结构:
   对账单工具_打包版/
   ├── 启动.bat
   ├── backend/
   └── frontend/

❌ 原因 6: 端口 8000 被占用
───────────────────────────────────────────────────

症状：
• 启动后报错
• 提示端口已被使用

解决方法：
1. Win+R 输入 cmd 回车
2. 输入: netstat -ano | findstr "8000"
3. 如果有输出，说明端口被占用
4. 找到占用的程序并关闭
5. 或重启电脑

【诊断工具使用方法】

我已经为你准备了两个诊断工具:

1️⃣ 诊断问题.bat
   - 双击运行
   - 会自动检测所有可能的问题
   - 并给出详细的解决建议

2️⃣ 启动_增强版.bat
   - 比原版启动脚本更详细
   - 每一步都有提示

【推荐的排查顺序】

第一步：双击 "诊断问题.bat"
   → 看看具体是哪个环节出问题

第二步：根据诊断结果修复问题
   → 通常是 Python 没装或没加 PATH

第三步：双击 "启动_增强版.bat"
   → 看详细的启动日志

第四步：如果还是不行
   → 截图错误信息发给技术支持


【终极解决方案】

如果以上都不行，使用命令行手动启动:

1. Win+R 输入 cmd 回车

2. 执行以下命令（一行一行输入）:

   cd /d D:\对账单工具_打包版\backend
   （注意：改成你的实际路径）

   python --version
   （检查 Python 是否可用）

   python main.py
   （手动启动程序）

3. 看看具体报什么错
   → 截图发给技术支持


【常见错误信息解读】

错误: python 不是内部或外部命令
→ Python 未安装或未加 PATH

错误: No module named 'fastapi'
→ 依赖库未安装，运行:
   python -m pip install -r requirements.txt

错误: Address already in use
→ 端口 8000 被占用，关闭占用程序或重启电脑

错误: Permission denied
→ 权限不足，右键"以管理员身份运行"
